# Security policy

LeanPhy is a proof-producing research library.  A security issue includes a
workflow that accepts an unchecked proposition, certificate, or external result
as a kernel-checked claim, or a release script that reports a broken fixture as
success.

Please report such issues privately to the repository maintainers before
publishing a proof-of-concept.  Include the affected commit, a minimal Lean
file or command sequence, expected behavior, and observed behavior.  Do not
include confidential physical data in an issue or pull request.

Ordinary theorem gaps and missing mathematical formalisation belong in public
issues with an explicit `open obligation` label.
